# 2-Back 疲劳诱发实验使用指南

## 1. 实验原理

2-Back 任务是一种经典的工作记忆任务，通过要求参与者在序列刺激中判断当前刺激是否与前 2 个刺激相同，来诱发认知负荷和疲劳。该任务被广泛应用于认知神经科学和疲劳研究中，能够有效激活前额叶皮层，反映工作记忆容量和注意力控制能力。

### 核心机制
- **刺激序列**：随机生成字母序列，其中 28% 左右为目标刺激（与前 2 个字母相同）
- **反应要求**：当出现目标刺激时按下空格键，非目标刺激时不按键
- **认知负荷**：需要持续更新工作记忆中的刺激信息，同时抑制无关信息干扰
- **疲劳诱发**：通过长时间（通常 10-20 分钟）的任务执行，逐渐累积认知疲劳

## 2. 系统要求

### 硬件要求
- **计算机**：支持 Windows/Linux/macOS 操作系统
- **浏览器**：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+（推荐使用 Chrome）
- **网络连接**：稳定的本地网络连接（前后端通信）
- **可选设备**：EEG 设备（用于记录脑电数据，支持 UDP 触发信号）

### 软件要求
- **前端**：Vue 3 + Element Plus + Vue Router
- **后端**：FastAPI + Python 3.8+
- **数据库**：MySQL/TiDB Cloud
- **依赖包**：详见 `requirements.txt` 文件

## 3. 操作流程

### 3.1 进入实验
1. **登录系统**：打开 WaveTune 系统，登录您的账号
2. **选择模块**：点击顶部导航栏的 "快速检测" 菜单项
3. **选择实验类型**：在选择页面中点击 "2-Back 疲劳诱发实验" 按钮

### 3.2 实验准备
1. **阅读实验说明**：仔细阅读实验目的、操作要求和注意事项
2. **设置实验参数**（可选）：
   - 实验时长：默认 10 分钟
   - 每轮试次数：默认 20 次
   - 实验轮数：默认 2 轮
   - 刺激持续时间：默认 1000ms
   - 刺激间隔时间：默认 1000ms
   - 休息时间：默认 60 秒
3. **确认开始**：点击 "开始实验" 按钮进入实验界面

### 3.3 实验过程
1. **刺激呈现**：屏幕中央会依次显示字母刺激
2. **任务要求**：
   - 当当前字母与前 2 个字母相同时，按下空格键
   - 当当前字母与前 2 个字母不同时，不按键
3. **实时反馈**：
   - 正确反应：显示绿色 "✓" 图标
   - 错误反应：显示红色 "✗" 图标
   - 反应时：显示您的按键反应时间
4. **轮间休息**：每轮实验结束后，会有 60 秒的休息时间

### 3.4 疲劳评估
1. **KSS 量表**：实验结束后，填写 Karolinska 睡眠量表（KSS）
2. **评分标准**：1-9 分，1 表示非常清醒，9 表示非常困倦

### 3.5 结果分析
1. **实时结果**：实验完成后，系统会自动分析您的表现
2. **数据指标**：
   - 命中率：正确识别目标刺激的比例
   - 虚报率：错误识别非目标刺激的比例
   - 平均反应时：正确反应的平均时间
   - 疲劳评分：KSS 量表得分
3. **可视化图表**：系统会生成表现趋势图和疲劳变化图
4. **数据导出**：支持将实验数据导出为 CSV 格式

### 4.2 EEG 触发信号

系统支持通过 UDP 协议发送 EEG 触发信号，用于同步脑电数据采集。触发信号格式如下：

| 触发码 | 含义 |
|-------|------|
| 100 | 实验开始 |
| 10 | 目标刺激呈现 |
| 11 | 非目标刺激呈现 |
| 20 | 按键反应 |
| 120 | KSS 量表开始 |
| 121 | KSS 评分提交 |
| 199 | 实验结束 |

**配置方法**：在实验准备页面的 "EEG 设备设置" 中填写设备 IP 和端口。

## 5. 常见问题与解决方案

### 5.1 前端问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 实验启动失败 | 网络连接问题 | 检查网络连接，刷新页面重试 |
| 按键无反应 | 浏览器焦点问题 | 确保实验界面获得焦点，点击页面后再按键 |
| 刺激显示异常 | 浏览器兼容性问题 | 更换为 Chrome 浏览器 |
| 页面卡顿 | 设备性能问题 | 关闭其他占用资源的程序 |

### 5.2 后端问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| API 请求失败 | 后端服务未启动 | 启动后端 FastAPI 服务 |
| 数据库连接失败 | 数据库配置错误 | 检查 `config/database.py` 中的数据库配置 |
| 触发信号发送失败 | UDP 配置错误 | 检查 EEG 设备 IP 和端口设置 |
| 数据存储失败 | 数据库权限问题 | 确保数据库用户有写入权限 |

### 5.3 实验相关问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 反应时过长 | 任务难度过高 | 适应实验节奏，保持注意力集中 |
| 正确率过低 | 注意力不集中 | 确保实验环境安静，避免干扰 |
| 疲劳感过强 | 实验时长过长 | 适当调整实验时长参数 |
| EEG 数据不同步 | 触发信号丢失 | 检查网络连接和设备设置 |

## 6. 数据安全与隐私

### 6.1 数据存储
- 实验数据存储在 TiDB Cloud 数据库中，采用加密传输和存储
- 所有数据均通过会话 ID 和参与者 ID 进行匿名化处理
- 数据库访问需要严格的身份验证和授权

### 6.2 隐私保护
- 参与者可以选择是否保存实验数据
- 数据仅用于科学研究和个人疲劳评估，不用于其他目的
- 遵循 GDPR 和相关数据保护法规
- 参与者有权随时删除自己的实验数据

## 7. 实验设计建议

### 7.1 研究应用
- **认知疲劳评估**：通过 2-Back 任务表现和 KSS 评分评估疲劳程度
- **干预效果验证**：比较干预前后的任务表现变化
- **个体差异研究**：分析不同人群的认知疲劳特征
- **脑电关联分析**：结合 EEG 数据研究疲劳的神经机制

### 7.2 实验参数调整

| 研究目的 | 推荐参数 |
|---------|----------|
| 轻度疲劳诱发 | 5 分钟，2 轮，每轮 15 次 |
| 中度疲劳诱发 | 10 分钟，2 轮，每轮 20 次 |
| 重度疲劳诱发 | 15-20 分钟，3 轮，每轮 25 次 |
| 认知能力评估 | 5 分钟，1 轮，每轮 20 次 |

### 7.3 控制变量
- **实验环境**：安静、舒适的实验环境，避免干扰
- **时间安排**：避免在饭后、睡前等特殊时段进行
- **参与者状态**：确保参与者充分休息，避免在疲劳状态下开始实验
- **指导语一致性**：使用标准化的实验指导语
